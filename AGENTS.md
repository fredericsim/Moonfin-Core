# Repository Instructions

## Upstream repository safety

- Treat the parent/upstream repository (`Moonfin-Client/Moonfin-Core`) as strictly read-only.
- Never open a pull request against upstream.
- Never push commits, branches, tags, comments, reviews, labels, workflow actions, or any other changes to upstream.
- Fetching and reading upstream is allowed only to update or rebase this fork.
- All branches, pull requests, merges, and other repository mutations must target the user's fork (`fredericsim/Moonfin-Core`) unless the user explicitly replaces these instructions in `AGENTS.md`.
